# Інтеграція — поточна версія Fudo

Це один Next.js-проєкт: **не треба вкладати ZIP усередину ZIP**. Розпакуйте архів, відкрийте `fudo_full_upgrade` у VS Code та виконайте інструкцію `START_HERE.md`.

- Головна `/` реалізована за скриншотами Нестора та використовує наданий логотип (оригінального коду головної в архіві не було).
- Андрій: `/maps`, OSM та гуртожитки.
- Ігор: `/group-orders`, **тільки демо**.
- Юрій: акаунти й `/settings`.
- Маркіян: окремий код каталогу ще не отримано.

Деталі — `TEAM_INTEGRATION.md`.
