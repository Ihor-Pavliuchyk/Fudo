# Технічна перевірка Fudo — 11.11.2026

## Успішно

- Перевірено наявність усіх базових маршрутів, спільного хедера та вкладених модулів.
- Застосовано оригінальний наданий логотип та створено адаптовані варіанти для хедера, футера й favicon.
- Головну створено за дизайн-референсами (desktop/mobile), додано працездатний пошук/категорії на демонстраційних масивах.
- На `/group-orders` прибрано дубльований внутрішній header. Бізнес-логіка замовлень лишилася попередньою.
- `npm test`: **14 / 14 тести пройдено** (бізнес-логіка, маршрути, навігація, логотип, фільтри, сумісність).
- Парсер TypeScript: **43 / 43 TS/TSX-файли** без синтаксичних помилок.
- CSS-класи, на які посилається головна сторінка, присутні в `app/home.module.css`.

## Не протестовано

- `npm install`, `npm run build`, `npm run typecheck` з повними npm-залежностями: у цьому середовищі встановлених залежностей немає. Відповідно, **успішну production-збірку та browser QA не підтверджено**.
- Реєстрацію, відновлення пароля та сповіщення з реальною БД PostgreSQL і поштовим провайдером.
- Доступність і реальні дані OpenStreetMap у всіх мережевих умовах.
- Адаптацію в реальних браузерах/телефонах; є CSS media queries, але немає перевірених скриншотів.

## Обмеження прототипу

Знижки та відгуки на головній — демонстраційні. Групові замовлення й оплати — локальна симуляція, акаунти не пов'язані з нею. Відсутній оригінальний код Нестора, відсутній каталог Маркіяна. Для готового продукту потрібні подальша інтеграція і end-to-end тестування.
