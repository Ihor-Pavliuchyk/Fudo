# Оновлення карти Fudo

- Замість чотирьох вигаданих точок карта завантажує нанесені в OpenStreetMap магазини чотирьох мереж у межах Львова.
- Дані надходять із Overpass API через серверний `/api/stores` з кешуванням 24 години. Кількість точок залежить від покриття OSM і доступності сервісу.
- На мітках видно назви мереж і їх відмінні кольори; це стилізовані текстові позначки, а не офіційні графічні логотипи.
- Якщо Overpass недоступний, інтерфейс повідомить про помилку і не підставлятиме вигадані магазини.
- Перед комерційним запуском варто зберігати перевірені точки у власній базі та отримати дозволи на офіційні логотипи.
- Запуск: `npm install`, `npm run dev`.
