# Fudo — спільний командний прототип

Єдиний Next.js / React / TypeScript застосунок, складений із доступних командних архівів і візуальних референсів.

- **Нестор:** нова головна сторінка `/`, відтворена **за його desktop/mobile скриншотами**. Оригінального вихідного коду головної сторінки в отриманих ZIP немає, тому це нова реалізація за макетом, а не дослівне злиття його репозиторію.
- **Андрій:** `/maps`, мітки магазинів, OSM API, гуртожитки з початкового ZIP.
- **Ігор:** `/group-orders` і бізнес-логіка групового замовлення з ZIP Андрія. Оплата — **симуляція**, дані у localStorage.
- **Юрій:** `/login`, `/register`, відновлення пароля, профіль і `/settings`, підтримка, сповіщення, серверна авторизація.
- **Маркіян:** окремого коду каталогу магазину немає в наданих архівах; його модуль **не вбудовано**.

Оригінал наданого логотипу — `public/brand/fudo-logo-original.png`. Адаптовані версії — у тій же папці. Референси макетів — `design-reference/`.
